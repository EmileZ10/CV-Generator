# CV-Generator

FastAPI + SQLModel (SQLite) + Jinja2 app for building and displaying a portfolio/CV from a form.

## Agent skills

### Issue tracker

Issues and specs live as GitHub issues in `EmileZ10/CV-Generator`, managed via the `gh` CLI. See `docs/agents/issue-tracker.md`.

### Triage labels

The five canonical triage roles, each mapped to a label string of the same name (`needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`). See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: one `CONTEXT.md` and one `docs/adr/` at the repo root. See `docs/agents/domain.md`.
